# Gerber Files Folder

Place the exported Gerber and drill files here after completing the KiCad PCB layout:

- `*.gbr` files for each copper, silkscreen, and mask layer
- `*.drl` drill file in Excellon format
- `gerbers.zip` — all of the above zipped for PCB fab submission

Refer to `kicad/README.md` for the full list of required Gerber layers and export instructions.
