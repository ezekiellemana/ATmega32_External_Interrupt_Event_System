# Interrupt Configuration

## Button Wiring — Active-LOW with Internal Pull-Up Resistors

All three push buttons are wired between the MCU input pin and GND. No external pull-up resistors are needed because the ATmega32 internal pull-up resistors are enabled in firmware by writing a `1` to the corresponding PORTx bit while the pin is configured as an input (DDRx bit = 0).

When the button is **not pressed**: the pin is held HIGH by the internal pull-up.
When the button is **pressed**: the pin is pulled LOW by the direct connection to GND.

This produces a falling edge (HIGH → LOW transition) on each button press, which is the trigger condition configured for all three external interrupts.

---

## Falling-Edge Trigger Configuration

### INT0 (PD2) — Emergency Stop

Configured in the `MCUCR` register:

| Bit | Name | Value | Meaning |
| --- | --- | --- | --- |
| ISC01 | Interrupt Sense Control 0 bit 1 | 1 | |
| ISC00 | Interrupt Sense Control 0 bit 0 | 0 | Together: falling edge triggers INT0 |

```c
MCUCR |=  (1 << ISC01);
MCUCR &= ~(1 << ISC00);
```

### INT1 (PD3) — Event Pulse

Configured in the `MCUCR` register:

| Bit | Name | Value | Meaning |
| --- | --- | --- | --- |
| ISC11 | Interrupt Sense Control 1 bit 1 | 1 | |
| ISC10 | Interrupt Sense Control 1 bit 0 | 0 | Together: falling edge triggers INT1 |

```c
MCUCR |=  (1 << ISC11);
MCUCR &= ~(1 << ISC10);
```

### INT2 (PB2) — Recovery / Reset

INT2 uses a single sense control bit in the `MCUCSR` register:

| Bit | Name | Value | Meaning |
| --- | --- | --- | --- |
| ISC2 | Interrupt Sense Control 2 | 0 | Falling edge triggers INT2 |

```c
MCUCSR &= ~(1 << ISC2);
```

All three interrupts are enabled together via the `GICR` register after configuration:

```c
GICR |= (1 << INT0) | (1 << INT1) | (1 << INT2);
```

## ISR Actions

| Interrupt | Pin | Trigger | ISR Behaviour |
| --- | --- | --- | --- |
| INT0 | PD2 | Falling edge | Sets `emergency_mode = 1`. Red LED and buzzer turn ON. Event counting locks immediately. |
| INT1 | PD3 | Falling edge | Increments `event_count` only when `emergency_mode == 0`. No count change during emergency. |
| INT2 | PB2 | Falling edge | If `emergency_mode == 1`: clears it (recovery). If `emergency_mode == 0`: resets `event_count` to zero. |

## Software Debounce Logic

Mechanical push buttons produce multiple rapid transitions (contact bounce) during a single press. Without debouncing, each press can generate several false interrupts.

### Implementation

A 1 ms system tick is generated by Timer0 in CTC mode:

- Clock: 8 MHz
- Prescaler: 64 → timer frequency = 125 kHz
- OCR0 = 124 → compare match every 1 ms
- `TIMER0_COMP_vect` ISR increments `system_ms` each match

Each interrupt source has its own `last_intN_ms` timestamp. Inside each ISR, the interrupt is only acted on if at least 200 ms have passed since the last accepted event:

```c
uint32_t now = system_ms;
if ((now - last_int0_ms) >= DEBOUNCE_MS) {   // DEBOUNCE_MS = 200
    /* accept this event */
    last_int0_ms = now;
}
```

This means a button must be released and re-pressed with a gap of at least 200 ms before it registers again, reliably eliminating bounce artifacts.
